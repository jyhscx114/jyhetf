# 金永昊精选ETF净值

按 14 只成分股的给定权重合成观察净值。每个交易日以各成分股的首笔开盘价为基准，开盘净值记为 1.0000。

## 功能

- 1 分钟、5 分钟、15 分钟 K 线
- MA5、MA10 与加权成交额
- 成分股涨跌、权重和净值贡献
- 桌面与移动端响应式布局

## 本地运行

最简单的使用方式：双击项目根目录的 `金永昊精选ETF净值.html`。这是已经内联 CSS、JavaScript 和图表的单文件版本，不需要 Node.js，也不需要本地服务器。

开发模式：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建完成后会将单文件版本同步到项目根目录，方便直接双击打开。

## 行情与口径

- 1 分钟 K 线：新浪财经公开行情接口
- 实时报价：腾讯证券公开行情接口，约 10 秒轮询
- 合成净值：`Σ(成分股权重 × 成分股现价 / 成分股今日开盘价)`

该页面是权重观察工具，不代表正式基金净值，也不构成投资建议。公开行情可能存在延迟。
